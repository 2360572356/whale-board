# 小鲸鱼的棋牌桌 · whale-board

终端里下棋的小东西。零依赖，装个 Node 就能跑，带一个不怎么会让你赢的 AI。

```
node play.js
```

```
小鲸鱼的棋牌桌
  1) 五子棋   2) 黑白棋   3) 井字棋   q) 退出
```

## 有什么

**五子棋**（15×15）
你执黑先手，输坐标就行，`H8` 或 `8H` 都认。
AI 的思路很土但够用：只考虑已经有子的格子周围两格，先找自己能不能连五、再找你是不是快连五，剩下的按"四/三/二 + 活口"打分，进攻分一分、防守分打九折。

**黑白棋**（8×8）
你执黑先手，输 `D3` 或 `3D`。两边都没得下的时候自动跳过，下完直接数子。
AI 是 minimax 加 alpha-beta，深度 4，用一张角位权重表算分，所以它抢角抢得很起劲，别把角白送它。

**井字棋**（3×3）
就这么大点地方，AI 是穷举的，最好结果是和棋。

## 用

```
git clone <仓库地址>
cd whale-board
node play.js
```

要是在任意目录下用，可以 `npm link`，之后直接敲 `whale-board`。

- 输入 `q` 退出
- 三副棋都认 `u`（或 `悔棋`）：退回自己上一次落子之前，AI 那手一起收回去
- 黑白棋里输入 `p` 认输
- 不认识的坐标会让你重输，不会崩

Node 16 往上都行，没装任何 npm 包。

## 结构

```
play.js       全部代码，一个文件，分三段：五子棋 / 黑白棋 / 井字棋
package.json  零依赖，CommonJS
```

想加新棋就照样子写一个 `playXxx()`，在 `main()` 里挂个序号。
